# Canoroid สำหรับ EOS 600D

รุ่นทดสอบขั้นแรกสำหรับ Canon EOS 600D เฟิร์มแวร์ **1.0.2** ใช้ JPEG หนึ่งไฟล์จากการ์ด ครอปตรงกลางเป็น 1:1 และใส่กรอบลงใน JPEG ใหม่ขนาด 1080 × 1080 พิกเซล Canoroid ใช้หน้าจอของตัวเองและแสดงภาพที่เปิดอ่านกลับจากไฟล์ที่เขียนแล้ว

## บิลด์และแพ็ก

ใช้ GNU Make, GCC สำหรับเครื่องบิลด์, GCC/binutils/newlib headers สำหรับ `arm-none-eabi`, Python 3, curl และเครื่องมือ tar กับ sha256sum ใช้เชลล์ Linux จากโฟลเดอร์ firmware

```sh
make -C platform/600D.102 clean
make -C platform/600D.102 -j4 CANOROID=y canoroid-packages
```

ไฟล์อยู่ใน `platform/600D.102/build/` ตั้ง `ARM_BINPATH` หากเครื่องมือ ARM อยู่นอก `/usr/bin` บิลด์ Canoroid ปิด TCC และโมดูลเสริม และตัวลิงก์ตรวจขอบเขตหน่วยความจำบูตของ 600D ก่อนแพ็ก หากสลับไปบิลด์ฐาน Magic Lantern ให้รัน `clean` ก่อน

- **FIRST-INSTALL** มี `ML-SETUP.FIR` ที่ Magic Lantern จัดให้สำหรับรุ่นนี้ ใช้การ์ดทดสอบ FAT32 คัดลอกไฟล์ที่แตกแล้วลงรากการ์ด ตรวจเฟิร์มแวร์และแบตเตอรี่ก่อนเข้าเมนู Firmware ของ Canon เพื่อเรียกตัวติดตั้ง
- **UPDATE** ใช้กับกล้องและการ์ดที่เปิดบูต Magic Lantern แล้ว คัดลอกไฟล์ที่แตกแล้วลงรากการ์ดโดยอัปเดต `autoexec.bin` และรวมโฟลเดอร์ `ML` สำรองข้อมูลการ์ดก่อนเปลี่ยนไฟล์ หากใช้การ์ดที่มีการตั้งค่า Magic Lantern จากรุ่นอื่น ให้ใช้การ์ดทดสอบแยกเพื่อให้ทราบว่าการตั้งค่าใดอยู่ในการทดสอบ

ทั้งสองแพ็กเกจเป็นบิลด์ทดสอบ การบูต การติดตั้ง การคืนหน้าจอให้ Canon และการเขียนการ์ดยังต้องตรวจบน EOS 600D จริง

## Canoroid v0.1.0-alpha (รุ่นที่ 9)

เลือกโหมด P, Av, Tv หรือ M และคุณภาพ JPEG หรือ RAW+JPEG ใช้การถ่ายทีละภาพบนจอหลังกล้อง

1. เปิดกล้อง เลือก Shoot with frame หรือ Monochrome print ด้วยปุ่มทิศทางและ SET
2. เลือกกรอบแล้วกด SET กล้องจะเข้าสู่ Live View เส้นนอกเป็นพื้นที่ 1:1 และเส้นในเป็นพื้นที่ภาพที่มองเห็นในกรอบ ใช้ Live View แบบขยาย 1×
3. กดชัตเตอร์ตามปกติ Canoroid ติดตามหมายเลขภาพ รอ JPEG บนการ์ด แล้วเริ่มเขียนและตรวจอ่านภาพใส่กรอบ เก็บไฟล์ใน ML/CANOROID ชื่อตามเลขโฟลเดอร์และเลขภาพของ Canon เช่น DCIM/100CANON/IMG_0123.JPG ได้ภาพใส่กรอบ 100_0123.JPG เมื่อเลขซ้ำจะใช้ 100A0123.JPG ถึง 100Z0123.JPG
4. เมื่อเห็นผล กดซ้าย/ขวาเพื่อเปรียบเทียบภาพต้นฉบับและภาพใส่กรอบของช็อตเดียวกัน ตัวอย่างทั้งสองวาดจากข้อมูล RGB ของภาพนั้น กด SET เพื่อถ่ายต่อ PLAY เพื่อกลับหน้าหลัก หรือ MENU เพื่อใช้ Canon
5. กด PLAY กลับหน้าหลักแล้วเลือก Shoot with frame เพื่อเลือกกรอบใบถัดไป หรือเลือก View photos เพื่อเปิด JPEG ใส่กรอบที่เก็บในการ์ด กดซ้ายหรือขวาเพื่อเลื่อนดู รองรับไฟล์รุ่นเก่า เช่น P0001.JPG หลังปิดและเปิดกล้องใหม่
6. หากขึ้น Print failed ให้จดสาเหตุและตำแหน่งไฟล์บันทึกบนจอ รายงานรายภาพอยู่ใน ML/CANOROID/E####.TXT หากบันทึกรายภาพไม่ได้ ระบบจะลองเขียนต่อท้าย ML/CANOROID.LOG

ผู้ใช้ทดสอบรุ่นที่ 7 บนกล้องจริงแล้วถ่ายครบสามใบ เปิดดูและเลื่อนภาพได้ รุ่นที่ 8 ขยายตัวอย่างบนจอจาก 240 เป็น 360 พิกเซลต่อด้าน ภาพใส่กรอบบนการ์ดขนาด 1080 × 1080 พิกเซล จาก View photos กดถังขยะเพื่อเปิดหน้ายืนยัน ระบบเริ่มที่ Cancel กดขวาเลือก Delete แล้วกด SET เพื่อลบเฉพาะภาพใส่กรอบที่ระบุชื่อบนจอ กด PLAY เพื่อยกเลิก

จากหน้าถ่ายภาพหรือเมนู Canon กดถังขยะเพื่อเปิดหน้าแรก หลังดูผลกด PLAY เพื่อกลับหน้าแรก รุ่นที่ 9 ออกจาก Live View ก่อนเปิดเมนูภาพนิ่ง เพื่อให้ปุ่มทิศทางและ SET ใช้เลือกงานได้ เมื่อเลือกกรอบแล้วกด SET กล้องจึงกลับเข้า Live View

หน้า Your print และ View photos ใช้แถบสีฟ้าและตัวอักษรขนาด 28 พิกเซลสำหรับชื่อไฟล์ ลำดับภาพ และวันที่ เวลา Captured มาจาก EXIF DateTimeOriginal ของ JPEG ต้นฉบับ รุ่นนี้บันทึกค่านี้ลง JPEG ใส่กรอบด้วย ถ้าไฟล์ไม่มีข้อมูลนี้จะใช้ป้าย File time สำหรับเวลาของไฟล์บนการ์ด หรือ Not recorded เมื่อไม่มีเวลาทั้งสองชนิด Print 3 / 5 หมายถึงภาพลำดับที่สามจากภาพใส่กรอบห้าใบที่มีอยู่ เมื่อลบภาพ ลำดับและจำนวนจะปรับตามไฟล์ที่เหลือ

## วิธีวาดจอที่ยืนยันบน 600D

ผู้ใช้ยืนยันว่ารุ่นที่ 8 แสดงภาพใหญ่และจอหยุดกะพริบบนกล้องจริง วาดทั้งหน้าลงบัฟเฟอร์พักภายใน BMP_LOCK แล้วคัดลอกขึ้นจอเมื่อวาดเสร็จ หน้าเดิมที่ไม่มีการกดปุ่มให้อ่านตัวอย่างพิกเซลเพื่อตรวจว่าถูก Canon วาดทับ วาดคืนเมื่อบัฟเฟอร์เปลี่ยนหรือมีส่วนเสียหาย วิธีนี้หลีกเลี่ยงการล้างจอจริงซ้ำระหว่างรอปุ่ม รุ่นที่ 9 ใช้วิธีเดิมกับพรีวิวสี และคืนพาเลตต์ให้ Canon เมื่อออกจากหน้าภาพ ผลสีบน LCD และการกลับเข้าเมนูของรุ่นที่ 9 ยังรอทดสอบบนกล้องจริง

## ทดสอบตัวประมวลผลบนคอมพิวเตอร์

```sh
make -C tools/canoroid
tools/canoroid/build/canoroid-print INPUT.JPG framed.jpg 1
python3 tools/canoroid/tests/card_session.py INPUT.JPG
```

เลือกกรอบด้วยเลข 1–3 เอาต์พุตต้องเป็นชื่อไฟล์ใหม่ ตัวทดสอบใช้โค้ดประมวลผลและตัวแปลง JPEG ชุดเดียวกับกล้อง แต่ใช้ระบบไฟล์ของเครื่องบิลด์

ทดสอบด้วย [JPEG ขนาดเต็มจาก EOS 600D](https://commons.wikimedia.org/wiki/File:Canon_EOS_600D_Example.jpg) และ JPEG ที่ฝังอยู่ใน [CR2 ของ EOS 600D จาก raw.pixls.us](https://raw.pixls.us/) ทดสอบครอป ขนาด ขอบสี การเปิดไฟล์ซ้ำ รวมถึงไฟล์ขาด ไฟล์เสีย JPEG แบบ progressive และการป้องกันเขียนทับเอาต์พุตเดิม
