Turn your EOS into an instant cam

กล้อง Canon EOS ของใครนอนเหงาอยู่ในตู้บ้าง? หยิบมาปัดฝุ่นแล้วออกไปถ่ายเล่นกัน! Canoroid เอาชื่อ Canon มาผสมกับ Polaroid ให้กล้องตัวเก๋าทำภาพโทนฟิล์มพร้อมกรอบได้จากหลังกล้อง แถมยังเก็บรูปต้นฉบับไว้บนการ์ดให้ด้วย

เลือกรุ่นกล้อง

ที่มาของ Canoroid

Canoroid เริ่มจากความอยากให้ EOS 600D ทำภาพใส่กรอบได้ตั้งแต่หลังกล้อง เราเขียนหน้าจอและขั้นตอนถ่ายสำหรับงานนี้บนฐาน Magic Lantern ใช้ตัวแปลง JPEG ของ Independent JPEG Group และศึกษาเทคนิคการแสดงผลจาก M-Film

ตารางสีอ้างอิงจาก luts-e-pl7 และงาน G’MIC ของ Pat David รายละเอียดแหล่งที่มาและใบอนุญาตอยู่ใน เครดิตโครงการ ภาพตัวอย่างทั้งสี่และภาพถ่ายที่ใช้ในคู่มือดัดแปลงจาก ภาพของ H982Falklands โดยครอป ใส่กรอบ และปรับโทน เผยแพร่ภาพตัวอย่างภายใต้ CC BY-SA 4.0

สี่โทน จากภาพเดียวกัน

ตัวอย่างจาก JPEG ของ EOS 600D ประมวลผลด้วยโค้ด Canoroid บนคอมพิวเตอร์ โดยใช้กรอบ Classic White เหมือนกันทั้งสี่ภาพ

มาสนุกกับกล้องสไตล์ Polaroid

ลองเริ่มจากของใกล้ตัวสักชิ้น แก้วกาแฟใบโปรดหรือเจ้าแมวที่นอนเฝ้าตู้กล้องก็ได้ หมุนแป้นไปที่ P, Av, Tv หรือ M แล้วเลือก JPEG หรือ RAW+JPEG ถ้าอยากเก็บไฟล์ RAW ด้วย

ภาพหน้าจอสร้างจากโค้ดวาดหน้าจอของ Canoroid v0.1.0 โดยใช้ภาพถ่ายและข้อมูลตัวอย่าง

เปิด Canoroid

จากหน้าถ่ายภาพ Canon กดปุ่มถังขยะ ครั้งแรกหลังเปิดกล้องจะเห็นหน้าปก 1 วินาที ครั้งต่อไปเข้าหน้าเลือกโทนทันที

Film tones · เลือกโทนและกรอบ

วันนี้อยากได้ภาพอารมณ์ไหน? ลอง Soft Film กับแสงเช้านุ่ม ๆ หรือ Vivid Color กับของเล่นสีสด ใช้ปุ่มทิศทางแล้วกด SET เลือกโทน จากนั้นลองเลื่อนดูกรอบทั้งเก้าแบบ เลือก No Frame เมื่อต้องการเฉพาะสีและขนาดเต็มของ JPEG ต้นฉบับ

Live View · เล็งแล้วถ่าย

กด SET เพื่อเข้า Live View ใช้เส้นกรอบเล็งภาพแล้วกดชัตเตอร์ทีละใบ รอให้กล้องทำภาพเสร็จก่อนถ่ายใบถัดไป ค่าถ่ายภาพใต้กรอบมาจาก EXIF ของภาพตัวอย่าง

Your print · เปรียบเทียบภาพ

กดซ้ายหรือขวาเพื่อเทียบต้นฉบับกับผลลัพธ์ ภาพแบบมีกรอบขนาด 1080 × 1080 พิกเซล บันทึกเพิ่มใน DCIM/CANOROID กด SET เพื่อถ่ายต่อ หรือ PLAY เพื่อกลับหน้าแรก

View Photos · เปิดอัลบั้ม

เลื่อนดูผลงานที่ถ่ายไว้ ถ้าใบไหนอยากลบ กล้องจะลบเฉพาะสำเนาที่ Canoroid สร้าง

Game · พาไดโนเสาร์ออกวิ่ง

ระหว่างรอเพื่อนมาถ่ายรูป เข้าเมนู Game แล้วลองเล่น DinoFrame Run สักรอบ กด SET ให้ Blue Trike กระโดดข้ามกลักฟิล์มในเกม DinoFrame Run กดลงค้างเพื่อก้มหลบกล้อง กดปุ่มที่กำกับว่า Pause บนจอเพื่อพักเกม

ดาวน์โหลดตามรุ่นกล้อง

ตรวจชื่อรุ่นและเลขเฟิร์มแวร์ในเมนู Canon ให้ตรงทั้งคู่ก่อนดาวน์โหลด สำรองข้อมูลในการ์ดและชาร์จแบตเตอรี่ให้เต็ม

ติดตั้งครั้งแรก

สำหรับการ์ด FAT32 ที่ยังไม่ได้ตั้งให้บูต Magic Lantern แตก ZIP ลงการ์ด แล้วใช้เมนู Firmware ของ Canon เรียกตัวติดตั้ง ML-SETUP.FIR

อัปเดตการ์ดเดิม

สำหรับกล้องและการ์ดที่บูต Magic Lantern หรือ Canoroid ได้อยู่แล้ว แตก ZIP วาง autoexec.bin ที่การ์ด และรวมโฟลเดอร์ ML เข้ากับของเดิม
