# Canoroid v0.2.0-alpha.1 · พอร์ตทดสอบ

ใช้ Canoroid v0.1.0 พร้อมเกม DinoFrame Run เป็นฐาน สำหรับ Canon EOS 550D (1.0.9), EOS 6D (1.1.6) และ EOS 650D (1.0.4) บิลด์ ARM และทดสอบการทำภาพบนคอมพิวเตอร์แล้ว ทั้งสามรุ่นยังรอผลจากกล้องจริง

[ไฟล์ทดสอบแยกตามกล้องและเฟิร์มแวร์](ports-preview/) · [รายละเอียดการบิลด์และทดสอบ](firmware/PORTS.md) · [รุ่นเผยแพร่สำหรับ 600D](https://github.com/pongallery/Canoroid/releases/tag/v0.1.0)

เลือก FIRST-INSTALL สำหรับการ์ดใหม่ หรือ UPDATE สำหรับกล้องและการ์ดที่บูต Magic Lantern ได้อยู่แล้ว ใช้ชุดที่ตรงกับรุ่นกล้องและเวอร์ชันเฟิร์มแวร์ Canon บนกล้องเท่านั้น

## ฐาน Canoroid v0.1.0 สำหรับ EOS 600D

เปลี่ยน Canon EOS 600D ให้ถ่ายภาพสไตล์อินสแตนต์ เลือกได้สี่โทน เก้ากรอบ หรือเลือก No Frame เพื่อเก็บ JPEG เต็มขนาด Canoroid เก็บไฟล์ต้นฉบับและสร้างภาพใหม่เพิ่มบนการ์ด

**รองรับ Canon EOS 600D เฟิร์มแวร์ Canon 1.0.2** ใช้ JPEG หรือ RAW+JPEG ในโหมด P, Av, Tv หรือ M หลังเปิดเครื่อง กดปุ่มถังขยะที่หน้าถ่ายภาพ Canon เพื่อเข้าโปรแกรม
